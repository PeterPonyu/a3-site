# a3-site

Public site leaf for https://github.com/PeterPonyu/a3-site.

- Live: https://peterponyu.github.io/a3-site/
- Archive: https://doi.org/10.5281/zenodo.21869995

This repository is the Next.js static export. It is not a published article and has no article DOI. The Pages site does not include figures, result numbers, journal skins, cover letters, or a method workbench.

```bash
NEXT_PUBLIC_BASE_PATH=/a3-site npm ci && npm run build && npm run verify
```
